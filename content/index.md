# ⚔️ Haven SMP — Servidor Minecraft Vanilla+ Crossplay

> **IP Java:** `crafty.inovati.cloud` | **IP Bedrock:** `crafty.inovati.cloud:19132`
> **Versão:** 1.21.8 (Minecraft 26.2) | **Crossplay:** Java + Bedrock

Servidor survival comunitário **Vanilla+** com crossplay entre Java e Bedrock. Sem mods obrigatórios — economia, RPG, cervejaria e 53 encantamentos custom rodam direto nos plugins. O foco é construir uma cidade juntos ao redor do spawn, cada um com sua casa, loja e profissão.

## 🚀 Como Entrar

### Java Edition
Abra o Minecraft Java (qualquer launcher, offline funciona), adicione o servidor **`crafty.inovati.cloud`** e entre.

### Bedrock Edition (Console, Celular, PC)
Vá em Servidores → Adicionar → IP **`crafty.inovati.cloud`**, porta **`19132`**, entre com sua conta Xbox.
